## Product variant clarification

The original sample source had only S, M, L and XL. The Add button became disabled when every available source variant was already included; four was not an implementation cap.

The quarter-zip demo source now contains S, M, L, XL, XXL and XXXL, while its initial four-row pouch still totals 30 pieces. The button reads “Add product variant to pouch.” When all source variants are included, adjacent help explains the exhausted source. Removing a row makes the source variant available again.

New sizes/colors are created in the B2C source Product editor, scheduled for Phase 6. They are then available to this wholesale composition editor. Native B2B products remain simple under the delivered contract. `PRODUCTS_FRONTEND.md` limits source variants to 100; `WHOLESALE_FRONTEND.md` limits a composition to 100 unique lines, each with 1–10,000 pieces. The interface must not claim unlimited support without a backend contract change.
